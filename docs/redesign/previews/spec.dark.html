Implementation notes
  • Display face is Newsreader. Bundle it as an asset (app is offline-first); Arabic stays on the existing reader fonts.
  • Tabular lining numerals on every time and count: FontFeature.tabularFigures() and liningFigures().
  • Dock: blurred surface with a hairline. Fall back to solid surface where blur is off.
  • Honour reduce motion for the sun arc and ring fills.
  • Layouts are LTR here. Arabic, Urdu and Persian locales need mirrored layouts: use EdgeInsetsDirectional and AlignmentDirectional throughout.
  • The 11 palettes are checked against 13 contrast pairs each. tokens.json holds the exact derived values to unit-test against.

Shape, spacing, rules
  • Radii: 12 small, 18 inputs, 22–24 cards, 28 hero and dock (EquranRadii.xl = 24; add 28).
  • Page gutter 20 (EquranSpacing.pagePadding). Section gap 36. Card padding 16 to 18. Rows 72 to 76 tall.
  • Cards are 1px hairline on surface, no drop shadow. Only the dock and bottom sheets cast a shadow.
  • Gold is for moments: the current prayer, favourites, streaks, the evening suggestion. Never plain chrome.
  • Hero panels (Duas suggestion, Prayer now) use featA → featB with gold ornament lines.
  • Touch targets are at least 44 × 44.
Components
  • Collections rail (Saved): 128 × 96 tiles, count in display numerals, active tile gets a gold hairline.
  • Verse card (Saved): reference medallion, Arabic first, translation, note panel (goldWash), folder and tag pills.
  • Theme tile (Duas): 2-column grid, one line icon per theme. Tap opens a themed category list.
  • Suggestion hero (Duas): Morning and evening remembrances by time of day, otherwise the last opened category.
  • Sun arc (Prayer): sunrise to Maghrib. Gold arc is elapsed time, the sun sits at now, dots mark Dhuhr and Asr.
  • Prayer list (Prayer): one grouped card, current row highlighted with NOW. Week strip replaces the prev / next bar.
  • Salah glyphs (Statistics): disc + check = on time, half disc = late, ring + bar = missed, dot = not logged, dashed ring = not yet.
  • Today rings (Statistics): outer gold = Quran goal, inner = salah of 5.
Where it lands in the code
  • Saved tab: lib/widgets/favourites_list.dart.
  • Duas: lib/duas/duas_page.dart (theme grid) and lib/duas/duas_category_page.dart (list).
  • Prayer: lib/prayer/prayer_times_page.dart, prayer_hero_card.dart, prayer_time_thumb_card.dart.
  • Statistics: lib/home/quran_stats_page.dart.
  • Theme: lib/theme/equran_colors.dart, equran_text_styles.dart, equran_spacing.dart, plus a new derived-tokens file.
  • Logic, repositories and data models do not change. Presentation only.
