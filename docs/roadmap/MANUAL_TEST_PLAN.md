# Manual test plan

Run on a low-RAM Android device, a current Android device, and Linux desktop where available. Record OS, build, locale, theme, performance mode, network state, and result.

1. Cold launch offline; confirm first screen, locale/theme, and no blocking error.
2. Open Quran, browse Surah/Juz/page, resume, direct ayah navigation, card/continuous views, RTL, large text, keyboard navigation.
3. Search Arabic with/without marks and translation; paginate, open result, change translation, repeat offline.
4. Start audio, change reciter, repeat interval/ayah, sleep timer, background/minimized player, disconnect/reconnect, download/remove audio.
5. Start Hifz, run listen/recall/rating, fail and pass cards, verify due date/log/streak and restart.
6. Create 7/30/60-day plan, complete a day, change date boundary, resume after restart.
7. Configure prayer coordinates/method/offset/high latitude; deny permissions; schedule/cancel reminders; inspect widget and Qibla calibration.
8. Use duas, daily content, Tasbih/dhikr, Hijri calendar, Zakat with manual and offline rates; verify source/timestamp/stale labels.
9. Export backup, edit/corrupt a copy, dry-run restore, restore valid data, confirm rollback and all selected sections.
10. Switch all supported locales and themes; check RTL, semantics, text scaling, contrast, landscape/tablet layouts.
11. Lite/Balanced/Enhanced: inspect effects, prefetch, animations, font window, search batches, and core-feature availability.
12. When each flag is enabled: Memory Map boundaries, Memory Twin explanations/reset/rescue, reviewed Constellation pack provenance/offline mode, two-device Halaqah expiry/authentication, Reciter Lens offline A/B, Capsule reminder/export/delete.
