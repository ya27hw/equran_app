# Amiri Quran

Quranic typeface from the Amiri project (copyright 2010–2022 The Amiri Quran
Project Authors), used for the Arabic surah names with full tashkeel on the
surah list and the reader's surah introduction card. It is a Regular-only
face, so text using it must not request a heavier weight.

Source: `AmiriQuran-Regular.ttf` from the
